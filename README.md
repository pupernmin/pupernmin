# Hi, I'm Yilin Mei 👋

**Robotics & VLA Engineer | Real-Robot Integration | Robot Learning & Deployment**

I'm a robotics and AI engineer focused on bridging **robot observations, learning-based policies, and executable actions**. I enjoy the engineering that happens between a model producing an action and a physical robot being able to use it reliably.

My background spans industrial computer vision, ROS 2 integration, multimodal robot data, imitation learning, and edge AI inference. I'm particularly interested in **robotic manipulation, teleoperation, and full-stack robot deployment**.

## What I work on

- **Robot learning:** demonstration-data preparation, HDF5 datasets, behavior cloning, SmolVLA fine-tuning, and action-chunk representations.
- **Perception & retrieval:** vision encoders, visual feature retrieval, and connecting perception outputs to downstream robot applications.
- **Edge deployment:** NVIDIA Jetson AGX Orin, PyTorch, TensorRT, and inference profiling.
